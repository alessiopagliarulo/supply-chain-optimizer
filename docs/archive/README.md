not curated for reading. Kept here for provenance rather than as part of the
documentation reading path. See [`../README.md`](../README.md) for the actual
reading path.

- [`MAINTENANCE-AND-KNOWN-ISSUES.md`](MAINTENANCE-AND-KNOWN-ISSUES.md) — what breaks on
  its own (the Monday collector vs. the model-CI gates, Render free-tier limits), what is

- [`AWS-MIGRATION-NOTES.md`](AWS-MIGRATION-NOTES.md) — how and why to redeploy this on
  ECS Fargate later, as a learning exercise rather than a hosting change.
